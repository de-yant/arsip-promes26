Pekan 17 — TP40 & TP43: Integrasi Elemen dan Pengelolaan File

Unit: 5 — Komputer Grafis  |  JP: 4  |  Bab: 3 Komputer Grafis

Menggabungkan Elemen Grafis

  • Impor foto (bitmap) ke software vektor
  • Buat elemen grafis (bentuk, garis, warna) sebagai pendukung
  • Tambahkan tipografi dengan hierarki yang jelas
  • Susun komposisi secara keseluruhan

Pengelolaan File Digital

  • Penamaan file yang konsisten dan terorganisir
  • Format file: pilih format yang tepat (PDF untuk cetak, PNG untuk web)
  • Backup: selalu cadangkan file ke harddisk eksternal/cloud
  • Reuse & recycling: gunakan kembali elemen desain dari proyek sebelumnya
  • Efisiensi: gunakan resources secukupnya, hindari pemborosan memori/energi

Tips

  • Simpan file dalam beberapa versi (v1, v2, final) untuk memudahkan revisi
