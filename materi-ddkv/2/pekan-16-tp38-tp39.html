Pekan 16 — TP38 & TP39: Prinsip Kerja Software Vektor dan Bitmap

Unit: 5 — Komputer Grafis  |  JP: 4  |  Bab: 3 Komputer Grafis

CorelDRAW (Vektor)

  • Interface: menu bar, toolbox, color palette, property bar, drawing window
  • Tools dasar: pick tool, shape tool, bezier, rectangle, ellipse, text
  • Teknik: membuat objek, coloring, tracing, shaping (weld, trim, intersect)
  • File format: .CDR (native), export ke AI, EPS, SVG, PDF

Adobe Illustrator (Vektor)

  • Interface: artboard, toolbar, panels, menu
  • Tools: pen tool, shape builder, gradient, mesh, envelope
  • Path editing: anchor point, bezier curve, pathfinder

Adobe Photoshop (Bitmap)

  • Interface: menu bar, toolbox, layers panel, options bar
  • Tools dasar: marquee, lasso, magic wand, pen tool, brush, eraser
  • Layer: konsep dasar, blending mode, opacity
  • Selection: cara memilih area gambar
  • Adjustment: brightness, contrast, hue/saturation, curves
  • Filter: blur, sharpen, noise, artistic
