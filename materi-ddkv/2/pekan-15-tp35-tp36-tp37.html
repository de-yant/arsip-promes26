Pekan 15 — TP35, TP36 & TP37: Bitmap, Vektor, dan Mode Warna

Unit: 5 — Komputer Grafis  |  JP: 4  |  Bab: 3 Komputer Grafis

Gambar Bitmap (Raster)

  • Terdiri dari kotak-kotak kecil bernama piksel
  • Resolusi menentukan kualitas: dpi (dots per inch)
  • Ukuran file besar, detail berkurang saat diperbesar
  • Format: JPG, PNG, BMP, TIFF, GIF
  • Cocok untuk: foto, shading kompleks, efek realistis

Gambar Vektor

  • Terdiri dari garis, kurva, dan bentuk matematika (path)
  • Tidak pecah saat diperbesar (skalabel)
  • Ukuran file kecil
  • Format: AI, EPS, SVG, CDR
  • Cocok untuk: logo, ikon, ilustrasi, desain cetak

Menentukan Penggunaan

  • Vektor untuk logo/ikon, bitmap untuk foto/tekstur

Mode Warna

  • RGB (Red-Green-Blue): untuk media digital/layar, additive color mixing
  • CMYK (Cyan-Magenta-Yellow-Key/Black): untuk cetak, subtractive color mixing
  • Sesuaikan mode warna dengan media output
